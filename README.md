# AML Alert Context Checklist

A practical template for testing what an investigator can see at the moment an AML alert opens. Use it on a sample of closed cases. It is a working exercise, not a compliance standard.

## How to use

1. Pick one alert type.
2. Sample 20 recently closed cases.
3. For each, record what was visible when the alert opened, not what was found later.
4. Score each element below.
5. Fix the most common gap first, then retest.

## Reading the result

- **Not available:** the information may never have been collected, or sits in another system.
- **Not current:** the record exists but is out of date.
- **Not linked:** the record exists under a different identifier.
- **No source shown:** the investigator cannot tell where it came from.

Each gap has a different fix. Classify before you choose a remedy.
